## Что такое Aurelia Genesis?

**Aurelia Genesis — эксперимент по искусственной жизни, вдохновлённый Fluctlight из _Sword Art Online: Alicization_.** Его цель — создавать когнитивных агентов, называемых здесь *синтетическими душами*, которые начинают с минимальных возможностей и постепенно формируют знания, память, предпочтения, связи и собственную идентичность через опыт.

Проект не задаёт им готовую личность и не скрывает чат-бота за интерфейсом. Он исследует восприятие, постоянную память, понятия, ассоциации и накопительное обучение на базе архитектуры [AERA](https://github.com/IIIM-IS/AERA), без LLM как источника интеллекта во время выполнения.

Genesis создаёт и поддерживает эти жизни. Первая популяция — **Naia, Orin и Iria**. У каждой изолированная память, разные начальные потребности и внутренние противоречия.

> **Примечание об интерфейсе и языках:** визуальный интерфейс отражает личный вкус автора и **не является самим проектом**. Основа Aurelia Genesis — внутренняя архитектура: обучение, память, развитие, изоляция, AERA и воспроизводимые эксперименты. Оформление может меняться, а производные версии могут свободно заменять его. Пока переводы проверяются, возможны языковые, грамматические и переводческие ошибки.

> **Личное примечание автора:** этот проект является одновременно исследованием и личным средством самовыражения и терапевтической поддержки в борьбе с депрессией. Автор пока неопытен и учится в процессе, поэтому следует ожидать ошибок, несовершенных решений, сбоев и даже периодов полной неработоспособности. Aurelia Genesis не заменяет профессиональную психотерапию, психологическую помощь или медицинское лечение.

### Текущее состояние

Это раннее исследование, а не завершённое искусственное сознание. Сейчас доступны три воспроизводимые личности, нативная интеграция AERA, локальный испанский словарь, начальная программа из 400 понятий и 2 000 связей, постоянная память и визуализация когнитивного развития.

[Публичная демонстрация](https://stabberrl.github.io/aurelia-genesis/) показывает визуальный слой Genesis Chamber. AERA, полные словари, обучение и постоянное когнитивное состояние работают локально.

> Проект исследует когнитивные архитектуры и накопительное обучение. Он не заявляет о создании сознания, биологических душ или цифровых личностей.

Цели, ограничения и процесс описаны в [`docs/objectives-and-process.md`](../objectives-and-process.md).

## Genesis Chamber

Визуальный интерфейс предназначен для локального наблюдения и взаимодействия. Он включает канал для приобретённого языка, формирующуюся идентичность, показатели целостности, любопытства и доверия, живое ядро, карту развития и адаптивную компоновку. Это только слой представления; реальная память и обучение запускаются локально.

## Предыдущее когнитивное ядро

AgentOS хранится в `vendor/agentos` только как историческая справка. Он исключён из исполнения, поскольку зависит от предобученной языковой модели.

```bash
git submodule update --init --recursive
```

## Текущее когнитивное ядро: AERA

[AERA](https://github.com/IIIM-IS/AERA) закреплена в `vendor/aera`. Genesis общается с ней через нейтральный протокол, доступный из JavaScript, Python и других языков без смешивания зависимостей. См. [`docs/aera-integration.md`](../aera-integration.md).

## Genesis

Genesis создаёт воспроизводимые популяции из `genesis.config.json`. Каждая душа получает совместимое с AERA зерно, административную идентичность, потребности, внутренний конфликт, состояние и полностью изолированную память.

```bash
npm run genesis:preview  # Предварительный просмотр
npm run genesis:birth    # Создание популяции
npm test                 # Проверка воспроизводимости и изоляции
```

Существующая популяция никогда не перезаписывается. Будущие миграции должны быть явными и проверяемыми.

### Локальная камера

```bash
npm start
```

Откройте `http://127.0.0.1:4747`. Мост не выдумывает ответы без подключения AERA. По умолчанию выбрана Naia; Orin и Iria спят.

```bash
npm run aera:build
npm run aera:start
```

`/api/health` показывает `connected: true` только после реального рукопожатия AERA. Начальные сигналы: свет, звук, контакт и энергия. Чат недоступен до приобретения языка. Безопасность описана в [`docs/security.md`](../security.md).

### Обучение на опыте

Принятые восприятия создают эпизодические воспоминания. Слово рядом с восприятием образует пластичную связь, усиливающуюся повторением и ослабевающую без подкрепления. См. [`docs/EXPERIENTIAL-LEARNING.md`](../EXPERIENTIAL-LEARNING.md).

### Когнитивный ритм

Бодрствующие души выполняют периодический цикл без LLM. Он оценивает развитие, консолидирует повторяющиеся свидетельства и записывает безопасное предложение следующей внутренней потребности. Внешние действия автоматически не выполняются.

Идея вдохновлена G.R.I.L.L.O. из Synthetic Heart, но реализована с нуля для AERA и Genesis без чужого кода, подсказок, персонажей или LLM.

### Основной тест: камера внешнего обучения

Genesis постепенно читает статьи Wiktionary через канал только для чтения. Данные очищаются, ограничиваются, дедуплицируются и сохраняются с источником, URL, языком, временем и статусом. Наблюдение определения **не означает понимания** и напрямую не повышает стадию развития.

Камера по умолчанию выключена. Включение: `FLUCTLIGHT_LEARNING_CHAMBER=1`; интервал задаёт `FLUCTLIGHT_LEARNING_INTERVAL_MS`. См. [`docs/ESSENTIAL-LEARNING-EXPERIMENT.md`](../ESSENTIAL-LEARNING-EXPERIMENT.md).

### Стадии развития

Оценочные стадии: **зарождение, раннее, среднее, продвинутое и высокое развитие**. Учитываются эпизодический опыт, заземлённые ассоциации, доказанный базовый язык, сенсорное разнообразие и автономные циклы. Предзагруженная программа сама по себе стадию не повышает.

> Стадии являются экспериментальными, неполными и пересматриваемыми оценками. Они не измеряют сознание, общий интеллект, достоинство или моральную ценность.

### Базовый тест: я, ты, да и нет

`npm run experiment:foundations` обучает Naia явными испытаниями и проверяет отложенные случаи, неоднозначность, сохранение, изоляцию Orin и контроль с перемешанными метками. [Визуальное доказательство](https://stabberrl.github.io/aurelia-genesis/proof.html) и [проверяемый отчёт](../../evidence/foundational-language-v1.md) открыты.

Результат показывает **ассоциативное различение собственной/внешней агентности и подтверждения/отрицания в контролируемой среде**. Это не доказательство самосознания или общего понимания языка.

### Словари и языки

Языки интерфейса и познания настраиваются отдельно. Испанский, английский, японский, русский, итальянский и французский используют изолированные базы. Смена когнитивного языка не переводит и не переносит память.

```bash
npm run lexicon:import-language -- --language=ru --download
```

Созданные базы не версионируются. Источники указаны в [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md), изменения с точным временем — в [`docs/CHANGELOG.md`](../CHANGELOG.md).

### Первая популяция

| Душа | Идентификатор | Начальное противоречие |
|---|---|---|
| Naia | `soul-001-alba-0001` | Принадлежность или независимость |
| Orin | `soul-002-ruma-0002` | Истина или гармония |
| Iria | `soul-003-rora-0003` | Долг или желание |

Административные файлы `GENESIS.json` не входят в перспективу душ. Видимые им файлы не упоминают AgentOS, Genesis, языковые модели или симуляции.
